# Security

## Что делает проект с секретами

- Ключи провайдеров хранятся в `%USERPROFILE%\.codex\codex-router\keys.dpapi`.
- Файл зашифрован DPAPI в контексте текущего пользователя (`CurrentUser`). Копия файла на другой
  машине или под другой учётной записью не расшифруется.
- На файл выставлен ACL `inheritance:r` с доступом только владельцу.
- Ключи не пишутся в логи, не попадают в аргументы процессов и не уходят в git.
- Переменные окружения `DEEPSEEK_API_KEY` и `MINIMAX_API_KEY` имеют приоритет над файлом.

## Что проект не защищает

- Локальный администратор машины может расшифровать ключи от имени пользователя — это свойство DPAPI.
- Мост слушает только `127.0.0.1`, но любой процесс под тем же пользователем может обратиться к нему.
- Тело запросов и ответов не логируется, однако провайдеры получают ваши промпты — это их обычная
  обработка запроса.

## Сообщить о проблеме

Пишите автору репозитория приватно, не открывайте публичный issue с деталями эксплуатации.
Если ключ мог утечь: перевыпустите его у провайдера и выполните

```powershell
.\scripts\codex-router.ps1 key -Provider deepseek -Key <новый>
```
